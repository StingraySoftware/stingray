Fixed incorrect results from the Lomb-Scargle fast Fourier transform (``lsft_fast``), which combined the sine and cosine sums in the wrong order and normalized by the number of frequencies instead of the number of observations. Bins with a degenerate sine basis (e.g. the exact Nyquist frequency on evenly sampled data) no longer return NaN: the imaginary part is set to zero where numerator and denominator both vanish, and recomputed from the direct sum elsewhere. The default oversampling factor is now 10 instead of 5, improving accuracy at some extra computational cost.
