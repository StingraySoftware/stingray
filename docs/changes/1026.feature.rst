``z_n_events_all``, ``z_n_events``, ``z_n`` and ``htest`` in ``stingray.pulse`` now accept per-event probability ``weights``, implementing the weighted :math:`Z^2_n` and H-test statistics of Kerr (2011, ApJ, 732, 38). For folded profiles of weighted events, ``z_n_binned_events_all``, ``z_n_binned_events``, ``z_n`` and ``htest`` accept ``total_variance``, and both ``z_n_search`` and ``epoch_folding_search`` accept ``variances`` (e.g. ``variances=weights**2``). Note that ``z_n_events_all`` is now a regular Python wrapper around its Numba kernel rather than a ``@jit`` function itself, so it cannot be called directly from user ``@njit`` code.

``stingray.stats`` now provides ``htest_probability``, ``htest_logprobability`` and ``htest_detection_level``, using the calibrated exponential distribution of de Jager & Büsching (2010, A&A, 517, L9) for ``nmax=20`` (which also holds for the weighted H-test; Kerr 2011, Section 2.2).
