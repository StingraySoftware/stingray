``intrinsic_coherence`` changes its estimate and its uncertainty. The bias of the squared cross spectrum is now P1 P2 / m, which includes the incoherent part of the signal, and the denominator is corrected for the correlation between the two powers. The result is no longer clipped to 0 or set to NaN at low powers (NaN only where a power is not above its noise level). The uncertainty, which followed Vaughan & Nowak 1997 eq. 8 with two typos and an error, is replaced by a 1-sigma interval that covers the true value about 68% of the time from zero to full coherence: ``return_interval=True`` returns its ends, ``return_uncertainty=True`` half its width.
