``stingray.utils.mad`` no longer behaves differently depending on whether the optional
``statsmodels`` package happens to be installed. It was imported from ``statsmodels``
when available and otherwise fell back to a local copy that defaulted to ``axis=None``
instead of the documented ``axis=0``, and that rounded the normalization constant to
``0.6745``. There is now a single implementation, built on
``scipy.stats.median_abs_deviation``, which returns exactly what ``statsmodels`` did.
As a side effect ``import stingray`` no longer pulls in ``statsmodels``, which it was
doing only for this one function, and is about half a second faster.
