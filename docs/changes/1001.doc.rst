- Forty-seven public functions and classes that were missing from their modules'
  ``__all__`` are now listed there, so ``automodule`` gives each of them a documentation
  page and cross-references to them resolve. Six classes that had no documentation at
  all -- ``DeadtimeFilterOutput``, ``EventReadOutput``, ``FITSTimeseriesReader`` and the
  three exceptions in ``stingray.modeling.posterior`` -- now have docstrings.
- Broken cross-references in the reStructuredText documentation are fixed. Sphinx is
  configured with ``default_role = 'obj'``, so every single-backtick span is an attempted
  Python object reference: the spans that were never meant to be links are now literals,
  and the ones that were meant to be links now carry the role and the module path they
  need. Two of them render as links for the first time. Such a failure is silent, so
  these were found by building with Sphinx's ``-n`` flag, which reports every reference
  that does not resolve.
- Fourteen classes that had a docstring but no entry in ``api.rst`` now have one, so
  they appear in the documentation at all: ``DeadtimeFilterOutput``, ``Window1D``,
  ``Optimal1D``, ``Multitaper``, ``TransferFunction``, ``GPResult``, ``StingrayWarning``,
  the three exceptions in ``stingray.modeling.posterior``, and ``RmsSpectrum``,
  ``LagSpectrum``, ``CovarianceSpectrum`` and ``ComplexCovarianceSpectrum``. Four whole
  modules were missing rather than one class each, so ``stingray.filters``,
  ``stingray.multitaper``, ``stingray.simulator.transfer`` and
  ``stingray.modeling.gpmodeling`` are now documented along with the public functions
  they contain.
- Thirteen reStructuredText errors in docstrings that had never been rendered are fixed,
  in ``stingray.filters``, ``stingray.multitaper`` and ``stingray.modeling.gpmodeling``.
- The cross-references in the docstrings are fixed too, which is the bulk of this change.
  Sphinx reported 509 unresolved references in docstrings; 24 are left, and they are
  accounted for. Four kinds of mistake: a type name such as ``np.array`` in a
  single-backtick span, which ``default_role`` turns into a request for an object of that
  name; a stingray class or function written without the role and module path Sphinx
  needs; a role whose backticks were put around the whole role instead of its argument,
  or left off altogether; and a bare class name in a base class's docstring, which is
  rendered again on every subclass page, where it no longer resolves. ``np.array`` alone
  accounted for 155 spans.
